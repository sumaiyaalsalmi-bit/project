# Evaluating Fairness in AI Writing Detection Models Using Explainable AI

This repository contains the Python notebooks associated with the research paper entitled "Evaluating Fairness in AI Writing Detection Models Using Explainable AI: A Case Study of Human- and Machine-Generated Essays."

## Repository Contents

- **Notebook 1 – Dataset1:** Model development, feature extraction, classification, performance evaluation and SHAP-based explainability.
- **Notebook 2 – Dataset2:** Within-dataset evaluation, cross-dataset generalisation and model performance analysis.

## Experimental Environment

The experiments were conducted using Python in Google Colaboratory.

## Research Objective

This study investigates the performance, interpretability and fairness-related concerns of AI writing detection models using human- and machine-generated essays.
